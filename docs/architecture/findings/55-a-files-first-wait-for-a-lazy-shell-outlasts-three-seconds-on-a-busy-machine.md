# 55. A file's first wait for a lazy shell outlasts three seconds on a busy machine

**Status:** Open · **Date:** 2026-10-12

**Evidence:** while finding 47 was reproduced (WEBBASE), the two tests of *the dashboard on a phone* (`apps/web/src/pages/dashboard/routes.component.test.tsx`, run alone with `-t`) were run 10 times with 12 busy loops on 12 cores, and another folder's component lane running beside them. In all 10 runs the first of them, "closes the drawer when another space is chosen in it", failed after about 3.2 s with `Unable to find role="button" and name "Menu"`: the space shell, imported lazily, had not arrived within the lane's 3 s wait ([finding 28](28-the-tests-that-wait-for-a-lazy-page-can-time-out-under-load.md)). Each run's first test pays Vite's first transform of the shell. Unloaded, both tests passed twice in a row. With 24 busy loops on 12 cores, both tests failed it. The same happens in full runs on this machine when other folders' lanes run beside it: in 9 full `test:component` runs (2 of `main` at `068efc6`, 7 of WEBBASE's branch), each 400–570 s against the lane's usual 250 s, "lists the owner’s eleven pages" (`routes.component.test.tsx`) failed in 7 with `Unable to find role="navigation" and name "Space dashboard"`, both of `main`'s included, and "shows its page to a guest, in the focus shell" (`authPages.component.test.tsx`) failed in 3 with `Unable to find role="main"`: the two tests of finding 28. One run also lost a Vitest worker at start (Windows exit code `0xC0000142`), and two tests ran past the 5 s test timeout. Finding 28's proof was full runs on a busy machine; this load is heavier. Whether CI's runner ever comes near it is not known.

**Resolves when:** a run shows how close CI comes to this load (the slowest wait for a lazy shell in a CI run, for example), and either the wait holds there with room, or the lane pays a shell's first transform outside the tests' wait, as `componentSetup.ts` pays jsdom's start-up ([finding 6](6-radix-component-tests-failed-once-under-load.md)).
