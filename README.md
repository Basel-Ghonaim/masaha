# Masaha · مساحة

A bilingual (Arabic / English) platform for coworking spaces in the Gaza Strip: a public directory with live available seats, and one role-based dashboard for space owners and the platform admin.

Graduation project — Al-Quds Open University, Gaza. Built by Basel Ghoneim.
